# GOZSter

Plataforma web y mobile (PWA) de alto rendimiento para la gestión de entrenamientos, rutinas y atletas de fuerza.

## Flujo de trabajo

1. Gabriel crea y asigna el issue a un agente `A-*`.
2. El agente trabaja en una rama `fix/<issue>-slug`, hace push y **no** abre PR.
3. Gabriel abre el PR y hace merge.
